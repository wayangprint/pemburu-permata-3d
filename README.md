# Pemburu Permata 3D

Game web 3D: kumpulkan 12 permata di pulau low-poly sebelum waktu habis, kalahkan boss, dan upgrade senjata.

## Cara main

- **PC:** WASD bergerak, mouse (seret) putar kamera, roda mouse zoom, Spasi lompat, F / klik tembak.
- **HP:** seret jari di area kiri untuk bergerak bebas, seret jari kedua / area kanan untuk putar kamera, cubit untuk zoom, ketuk 2 kali untuk lompat, tombol TEMBAK untuk menembak.

## Level kesulitan

- **Mudah:** 140 detik, Boss Bot Raksasa (HP 5, lambat)
- **Sedang:** 110 detik, Boss Raja Robot (HP 8, normal)
- **Sulit:** 85 detik, Boss Mecha Titan (HP 12, cepat + 2 penjaga)

## Upgrade senjata

- 3 permata: Blaster Bambu
- 6 permata: Blaster Ganda
- 9 permata: Blaster Plasma (damage 2)

Menang = semua 12 permata terkumpul + boss dikalahkan (+500 poin).

Prototype — satu file `index.html` mandiri (Three.js ter-bundle), tanpa backend.
